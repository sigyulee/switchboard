# Versions

Switchboard uses `MAJOR.MINOR.BUGFIX` versions. Feature releases increment the
minor version; compatible fixes increment the bugfix version. Incompatible product
or storage changes increment the major version.

The app displays the release version and channel, such as `1.3.1 beta` or `1.3.1`.
GitHub marks beta releases as prereleases, with tags such as `v1.3.1-beta`.
Stable releases use tags such as `v1.3.1`.
